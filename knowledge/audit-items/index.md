# JUNOS Compliance Audit Items

These concepts define machine-readable rules and expected expressions used to audit running network configurations for drift, security vulnerability, and operational resilience.

## Active Compliance Audits

* **[Enforce Secure SSH Only](sec-ssh-only.md):** Verifies secure SSH services and ensures Telnet is completely disabled.
* **[Ensure Telnet Management is Disabled](sec-telnet-disabled.md):** Identifies plaintext Telnet usage.
* **[Ensure No DDoS Protection Packet Drops](sec-ddos-protection.md):** Audits control plane DDoS packet statistics to identify active anomalies.
